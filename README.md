ElectrumSVP Test Scripts

A collection of Python test scripts used in designing ElectrumSVP.

Sync & Subscribe: Download full 74 MB headers from genesis and subscribe to new blocks.

BEEF & Merkle Extraction: Extract BEEFs, Merkle proofs, UTXOs, and transaction data.

Verification: Verify proofs with block headers and parse BEEF JSON.

Multi-server Testing: Compare scripthash status and confirmed transactions across ElectrumX servers.

Requirements: Python ≥3.7; some scripts require BitcoinX
